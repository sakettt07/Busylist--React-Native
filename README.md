# 📱 Local Business Listing App (React Native)

A beginner-friendly **React Native mobile application** built using **Expo and TypeScript**.  
The app allows businesses to list their services under different categories, and users can discover businesses using category-based filtering. Users can sign up and log in using **Google Authentication**.

The backend is powered by **Strapi (Headless CMS)** and images are stored and managed using **ImageKit.io**.

---

## 🚀 Features

- 🔐 Google Sign-In authentication
- 🏪 Business listing with categories
- 🔎 Category-based business search and filtering
- 🖼️ Image upload and management using ImageKit.io
- 📱 Cross-platform mobile app (Android & iOS)
- 🧑‍💻 Beginner-friendly codebase

---

## 🛠️ Tech Stack
